## 目标

在 D:\31702\localapi 从零建一个本地 API 中转站（OpenAI 兼容）：读 .env 得上游 api/model/key，本地端口同时提供 CLI 可用的 /v1/* 中转接口 + **Vue 管理网页**（API 密钥、使用记录、渠道+主题、今日 Token、余额，大厂后台完成度）。编码遵守 .simple-dev 预设（TypeScript、无装饰注释、禁 emoji 用内联 SVG、conventional commits、GPL-3.0、双语 README、AGENTS/CONTRIBUTING/.github 模板齐全）。

## 技术栈

**前端：Vue 3 全家桶，热门依赖逐个点名（这是本次重点）：**
- Vue 3.5（`<script setup>` + Composition API）+ TypeScript + Vite
- **Element Plus** —— UI 组件库，暗色/亮色双主题（`element-plus/theme-chalk/dark/css-vars.css` + 自定义 CSS 变量）
- **@vueuse/core** —— useDark 主题切换、useLocalStorage、useTitle、useDebounceFn、useFetch 等组合式工具
- **vue-echarts + echarts** —— 仪表盘折线/饼图/柱图（按需注册、图表自带动画）
- **@iconify/vue** —— 图标全部走 iconify 图标集（顺便满足 .simple-dev 禁 emoji 规则，界面零 emoji，全部 SVG 图标）
- **animate.css** —— 页面/卡片进场动画；路由切换过渡动画（<transition> + CSS）
- **Pinia + pinia-plugin-persistedstate** —— 状态管理，登录态与主题持久化
- **Vue Router 4** —— 路由 + 导航守卫（未登录拦截到登录页）
- **axios** —— HTTP 封装（拦截器统一带 Admin-Token、错误统一弹提示）
- **dayjs** —— 日期格式化与相对时间
- **sass** —— 样式变量与主题设计令牌
- **nprogress** —— 顶部路由加载进度条
- **unplugin-auto-import + unplugin-vue-components** —— Element Plus 组件与 vue/vue-router/pinia API 自动按需引入，模板不写 import 样板
- 动效细节：统计卡片数字滚动动画、悬停 elevation 效果、表格 loading 骨架屏、echarts 联动

**后端：Node.js 20 + TypeScript + Express + better-sqlite3（原生同步 API）+ dotenv，单进程**
**包管理：pnpm workspace（根 + web/）**

## 关键设计

**.env 变量**：PORT=3000、HOST=127.0.0.1、ADMIN_TOKEN、BASE_URL/API_KEY/MODEL（主渠道）、PRICE_IN/PRICE_OUT（每千 token 单价）、MODEL_MAP（本地名=上游名）、EXTRA_CHANNELS_JSON（可选多渠道 JSON）、BILLING_ENDPOINT（可选余额接口）。首次启动把 env 渠道种进 SQLite，之后以库里为准。

**SQLite 表**：api_keys（key_sha256 唯一、状态、累计用量）、channels（base_url/key/模型/单价/**主题名/主题色/图标**/开关）、usage（时间、渠道、模型、密钥、tokens、cost、latency、状态，建时间索引）、balance_cache（渠道、来源、金额、时间）。

**/v1/* 中转**：/v1/models、/v1/chat/completions、/v1/completions、/v1/embeddings；Bearer 校验本地密钥；按模型映射路由到渠道；stream:true 走 SSE 透传并在结束时记用量（响应带 usage 用真值，否则按字符估算）；错误返回 OpenAI 风格 JSON；CORS 全开。

**/admin/* 管理**：X-Admin-Token 校验；密钥 CRUD（明文仅创建时返回一次）；用量查询（时间/密钥/渠道筛选+分页+CSV 导出）；统计（今日 Token、今日请求、总消耗、7 日趋势、渠道/模型分布、每渠道余额）；渠道 CRUD + 主题编辑（名称/颜色/图标）+ 一键延迟测试；设置读写（单价、掩码后的 env 摘要）。

**余额（两者结合）**：渠道有 billing 接口（OpenAI 式 /v1/dashboard/billing/credit_grants）就实时查、缓存 60 秒；失败或无接口就按「配置额度 − 累计成本」本地估算，界面标注来源（实时/估算）。

**前端页面（全部 Vue 组件实现）**：
- 登录页：ADMIN_TOKEN 输入，优雅渐变背景 + 卡片进场动画
- 仪表盘：统计卡片（今日 Token/今日请求/总消耗/余额，数字滚动动画）+ ECharts 7 日用量折线 + 渠道占比环形图 + 模型用量柱状图
- 密钥管理：表格增删/复制/启用停用，每密钥用量，新建密钥弹窗只显示一次明文
- 渠道管理：卡片网格，主题色/图标编辑，延迟测试结果标签，开关启用
- 使用记录：表格 + 时间/密钥/渠道筛选 + 分页 + 导出 CSV
- 设置：数学 env 摘要（密钥掩码）、修改单价、默认主题
- 全局：暗/亮主题切换、nprogress 进度条、路由过渡动画、Element Plus 暗色变量

**构建运行**：pnpm dev（后端 tsx watch + vite 代理）；pnpm build（tsc + vite 构建到 dist-web）；pnpm start 单进程提供一切：/v1 中转、/admin 接口、静态网页（SPA fallback）。CLI 工具只需 base_url 指到 http://127.0.0.1:3000/v1。

**Git**：git init（当前非 git 仓库），.gitignore 先行，feat/localapi-relay 分支，conventional 风格提交。无远端仓库，PR 开不了，留本地分支提交。
