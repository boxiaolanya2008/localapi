# Contributing / 贡献指南

## Code Style / 代码风格

- No ornamental comments / 禁止装饰注释
- No emoji, use SVG / 禁止emoji，使用SVG
- Minimal syntax / 语法极简

## Pull Requests / 提交请求

1. Create feature branch
2. Make changes
3. Run tests
4. Submit PR

## Commit Messages / 提交信息

```
feat: add feature
fix: resolve bug
docs: update documentation
```
