# Simple Dev Preset / 简洁开发预设

极简代码风格的Agent预设。

## Features / 功能

- 指令遵守大于一切 / Instruction compliance > all else
- 无装饰注释 / No ornamental comments
- 禁止emoji（SVG替代）/ No emoji (use SVG)
- 代码语法极简 / Minimal syntax
- 自动创建PR / Auto-create PR
- 中英双语 / Bilingual
- 自主调用skills / Autonomous skill invocation
- GitHub规范文件 / GitHub standard files

## Usage / 使用

选择 "Simple Dev" 预设。
